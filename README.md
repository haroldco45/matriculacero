# 📚 Decreto 1667 de 2021 — Matrícula Cero
### Biblioteca Legal Colombiana · Vibras Positivas HM

---

## 📋 Descripción

PWA educativa que presenta de forma clara y accesible el **Decreto 1667 del 7 de diciembre de 2021**, norma que reglamenta el programa **Matrícula Cero** y los **alivios para usuarios del ICETEX**, en cumplimiento del artículo 27 de la Ley 2155 de 2021 (Ley de Inversión Social).

---

## 🎯 Contenido de la app

| Sección | Descripción |
|---------|-------------|
| **Resumen** | Ficha técnica, objeto, beneficiarios y marco institucional |
| **Artículos** | Acordeón con artículos 1, 2 y 3 y sus parágrafos |
| **Normativa** | Leyes, decretos y sentencias relacionadas |
| **Glosario** | 8 términos clave explicados en lenguaje ciudadano |
| **Consultas IA** | Asistente especializado en la norma vía Claude API |

---

## 🚀 Tecnología

- HTML5 / CSS3 / JavaScript vanilla — un solo archivo
- **PWA completa**: manifest.json + Service Worker para uso offline
- **Open Graph** para vista previa en WhatsApp y redes sociales
- **IA integrada**: Claude Sonnet via Anthropic API (proxy incluido)
- Diseño responsive optimizado para móviles
